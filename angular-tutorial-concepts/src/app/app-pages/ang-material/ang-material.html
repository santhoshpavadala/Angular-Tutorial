Section 12 — Angular Material & UI Architecture

This section is particularly relevant to your Angular frontend experience. Interviewers may ask how you build reusable UI components, manage API-driven tables, handle dialogs, and maintain consistent layouts across multiple application modules.

12.1 Angular Material fundamentals

Angular Material provides ready-made Angular components for common interface patterns.

                    
    Component	        Common use
    MatTable	        Display structured data
    MatPaginator	    Navigate between pages
    MatSort	            Sort table columns
    MatDialog	        Confirmation and editing dialogs
    MatSnackBar	        Temporary success/error messages
    MatFormField	    Consistent form-field layout
    MatInput	        Text input
    MatSelect	        Dropdown selection
    MatMenu	            Context menus and action menus
    MatProgressSpinner	Loading indicator
    MatTooltip	        Additional contextual information
    MatSidenav	        Navigation drawer or side panel

For standalone components, import the relevant Material modules or standalone directives/components supported by your installed Angular Material version.
