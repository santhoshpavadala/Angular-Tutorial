Rxjs Map & SwitchMap Operators

RxJS Operators - Quick Notes

1. map()

Transforms data from one format to another without changing the number of items. 

        Input  : User API Response
        Output : UserView Model

Use Case: Convert API response into UI-friendly data.

2. filter()

Filters items based on a condition and returns only matching records. 

        Input  : 10 Users
        Output : 5 Active Users

Use Case: Search, Active Users, Status Filtering, Company Filtering.

3. tap()

Performs side effects without modifying the data stream. 

        Input  : Users
        Output : Same Users

Use Case: Logging, Debugging, Loader Start, Analytics.

4. debounceTime()

Waits for a specified time before emitting the latest value. 

        User Types
        ↓
        Wait 500ms
        ↓
        API Call

Use Case: Search Inputs, Autocomplete.

5. distinctUntilChanged()

Ignores consecutive duplicate values. 

        Angular
        Angular
        Angular
        
        Output:
        Angular

Use Case: Prevent unnecessary API calls.

6. switchMap()

Cancels previous observable and switches to the latest observable. 

        Search A
        ↓ Cancel
        
        Search B
        ↓ Cancel
        
        Search C
        ↓ Execute

Use Case: Search, Route Params, Dynamic Filters.

7. combineLatest()

Combines multiple observables and emits the latest values from all. 

        Search
        +
        Company
        +
        City
        
        ↓
        
        [search, company, city]

Use Case: Dashboard Filters, Forms.

8. catchError()

Handles errors and allows the observable stream to continue. 

        API Error
        ↓
        Fallback Data

Use Case: API Error Handling.

9. finalize()

Executes when an observable completes, errors, or is unsubscribed. 

        API Call
        ↓
        Success/Error
        ↓
        Hide Loader

Use Case: Loader Cleanup, Resource Cleanup.

takeUntil automatically unsubscribes from an observable when another observable emits. 

        Observable
        ↓
        takeUntil()
        ↓
        Component Destroy
        ↓
        Unsubscribe

Use Case: Prevent Memory Leaks, Search Subscriptions, WebSockets, Route Params, Polling. 

            
                subscription!: Subscription;
                ngOnInit() 
                this.subscription =
                    this.userService.getUsers()
                    .subscribe();
                ngOnDestroy() 
                this.subscription.unsubscribe();

Multiple subscriptions -> Messy

Better Way

                    destroy$ = new Subject void();
                    
                    this.userService.getUsers().pipe(
                    takeUntil(this.destroy$)
                    )
                    .subscribe();

                    ngOnDestroy(): void 
                    this.destroy$.next();
                    this.destroy$.complete();
