Topic 4: Angular Pipes

Pipes

Q1. What is a pipe in Angular?

In Angular, a Pipe is used to transform data in the template before displaying it in the UI. It does NOT change the original data, it only transforms it for display.

Built-in examples:name | uppercase; price | currency; today | date; value | number

    Common built-in pipes include:
  • DatePipe
  • CurrencyPipe
  • DecimalPipe
  • PercentPipe
  • UpperCasePipe
  • LowerCasePipe
  • JsonPipe
  • SlicePipe

Q3. What is a custom pipe?

A custom pipe is created when the built-in pipes do not meet a particular display-transformation requirement.

                
                
 description | truncate:20

Q4. Pure vs Impure Pipes

A pure pipe is the default. It executes when Angular detects a change to its input value or reference. An impure pipe can execute during every relevant change-detection cycle.

            
                Pure pipe	                    Impure pipe
                Default	                        Requires pure: false
                Runs on input changes	        Can run frequently
                Usually more efficient	        May be more expensive
                Good for most transformations	Appropriate only for specific cases

A Pure Pipe is a pipe that Angular executes only when the input value or input reference changes. Pure pipes are optimized for performance because Angular avoids running them unnecessarily. By default, all Angular pipes are Pure Pipes.

                @Pipe(
                name: 'myPipe',
                pure: true
                )

An Impure Pipe is a pipe that Angular executes during every change detection cycle, regardless of whether the input reference changed or not. Impure pipes are useful when data changes internally without creating a new object or array reference.
The important part:
pure: false
This tells Angular to run the pipe on every change detection cycle.

                @Pipe(
                name: 'myPipe',
                pure: false
                )

Q5. Can we chain pipes?

Yes. The output of one pipe can be passed to another.

                    
 today | date:'fullDate' | uppercase

Q6. Can pipes accept parameters?

Yes. Parameters are passed after the pipe name using colons.

 amount | number:'1.2-2'

Q7. Why should expensive operations be avoided inside pipes?

Pipes can be evaluated as part of template update processing. Expensive transformations, especially in impure pipes, can affect rendering performance. Complex calculations may be better placed in a service or derived state.

Q. You need to filter and sort a large table. Would you use a custom pipe?

For a small, simple list, a pure custom pipe may be appropriate. For large data, frequent updates, or server-backed filtering, I would consider derived state, a dedicated data-processing layer, or server-side operations to avoid repeated expensive calculations.

Angular Pure and Impure Pipes

What is Pure Pipe?

A Pure Pipe is a pipe that Angular executes only when the input value or input reference changes.

Pure pipes are optimized for performance because Angular avoids running them unnecessarily.

By default, all Angular pipes are Pure Pipes.

Full name

{{firName | fullname:lasName}}

Uppercase

{{firName | uppercase}}

Tax of salary/p>

{{salary | tax}}

Angular recalculates only if salary changes.

Pure Pipe with Arrays

Users Count: {{users | usersCount}}

Advantages of Pure Pipes

  • Better Performance
  • Less CPU Usage
  • Recommended for Enterprise Applications
  • Runs Only When Needed

2. Impure Pipe

An Impure Pipe is a pipe that Angular executes during every change detection cycle, regardless of whether the input reference changed or not.
Impure pipes are useful when data changes internally without creating a new object or array reference.

The important part:

pure: false

This tells Angular to run the pipe on every change detection cycle.

@for (emp of employees | search : searchText; track emp.id) {
{{emp.name}}
}

Advantages of Impure Pipes

  • Detect Internal Changes
  • Good for Real-Time Data
  • Useful for Dynamic Filtering

Disadvantages of Impure Pipes

  • Runs Frequently
  • Can Affect Performance
  • Not Recommended for Heavy Calculations
  • Higher CPU Usage

A Pure Pipe executes only when Angular detects a change in the input value or reference. It is the default pipe type and provides better performance.

An Impure Pipe executes on every Angular change detection cycle, even if the reference does not change. It is useful for real-time filtering and dynamic data updates but can impact performance.
