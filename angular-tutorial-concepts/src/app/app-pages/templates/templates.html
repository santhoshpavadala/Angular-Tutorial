Topic 5: Template Reference Variable

Template Reference Variable

A Template Reference Variable in Angular is used to get a reference to an HTML element, Angular component, directive, or ng-template inside an HTML template.
We create a template reference variable using the # symbol.

Syntax: < input #username />

    Here:
  • #username creates a template reference variable.
  • username is the variable name.
  • We can access the input element using this variable inside the template.

1. Access HTML Elements

Example: Get the input value when clicking a button.

2. Template Reference Variable with Forms

We can use template reference variables to access form values and form status.

3. Template Reference Variable with Components

We can access a child component's public properties and methods through its template reference variable.
