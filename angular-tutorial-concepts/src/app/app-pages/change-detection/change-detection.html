Topic 7: Angular Change Detection

CHANGE DETECTION & PERFORMANCE

Change detection is the mechanism Angular uses to determine when the component view needs to be updated to reflect changes in application state.

For example, when a user clicks a button and a component property changes, Angular can update the displayed value.

9. How does Angular change detection work?

Angular runs a top-down check of components to detect data changes. Zone.js triggers detection when async tasks complete.

Consider this example:

When the button is clicked:

  1. Angular handles the event.
  2. The component's count value changes.
  3. Angular performs the necessary change-detection work.
  4. The view updates to show the new count.

10. What is OnPush strategy?

OnPush runs change detection only when: - Input reference changes - Event occurs - Observable emits - markForCheck() is called

11. Why is OnPush better for large apps?

It reduces unnecessary DOM checks and improves performance.

Example of OnPush:

With OnPush, Angular can check the component when, among other triggers:

  • A bound input receives a new value.
  • An event is handled in the component's view.
  • A signal read by the template changes.
  • The component is explicitly marked for checking.

9.3 markForCheck() and detectChanges()

These APIs allow explicit control over change-detection behavior.

markForCheck()

Marks a component so that Angular checks it during a subsequent change-detection run.

detectChanges()

Immediately checks the view and its relevant child views.

It can be useful for specialized cases, but frequent manual calls can make an application harder to reason about.

9.4 Change detection and Signals

Signals integrate with Angular's change-detection system.

When the signal changes, Angular knows that the template depends on it and can schedule the necessary update.

9.5 Zone.js and zoneless Angular

Traditionally, Angular has commonly used Zone.js to help detect asynchronous activity and initiate change detection.

Modern Angular also supports zoneless change detection, where Angular relies on explicit notifications such as signal updates, template events and other supported mechanisms rather than Zone.js patching asynchronous APIs.

                
 Interview questions
Q1. What is change detection in Angular?
It is the process Angular uses to synchronize the component state with the rendered view.

Q2. What is the difference between markForCheck() and detectChanges()?
markForCheck() marks a view for checking during a later change-detection run. detectChanges() immediately performs change detection for the view and its children.

Q3. Why is OnPush used?
It helps reduce unnecessary checks by making component checking more selective. It is particularly useful in large applications with reusable component trees.

Q4. Does OnPush mean a component will never update unless its input reference changes?
No. Events within its view, changes to signals read in its template, explicit marking and other supported notifications can also cause it to update.

Q5. What happens if you mutate an object passed to an OnPush child?
If the object reference remains unchanged, the input change alone will not trigger the child to be checked. Prefer immutable updates or use an appropriate reactive state mechanism.

2. How Angular Change Detection Works

Angular uses Zone.js to detect async events.

    Zone.js tracks things like:
  • Click events
  • HTTP requests
  • Timers (setTimeout)
  • Promises
  • Observables

Whenever one of these happens, Angular triggers a Change Detection Cycle.

Types of Change Detection Strategies

Angular provides 2 strategies.

1. Default Change Detection

This is the default behavior. Angular checks every component whenever any event occurs.

2. OnPush Change Detection

More optimized strategy.
Angular checks component only when specific conditions occur.

changeDetection: ChangeDetectionStrategy.OnPush

Now Angular will NOT check this component on every cycle.

OnPush triggers change detection only when:

  • Input reference changes
  • Event occurs in component
  • Observable emits value
  • Manual detection

Manual Change Detection

"Why does OnPush still update UI when clicking button?"

Even with ChangeDetectionStrategy.OnPush, Angular triggers change detection when events originate from the component such as click events. Therefore when the button click calls nameChange() and updates the value, Angular detects the change and updates the UI.
