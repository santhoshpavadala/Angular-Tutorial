What is a Route Parameter?

Route Parameters are dynamic values passed through the URL path and are typically used to identify a specific resource.

/user/1

Angular Route Gaurds Examples

Route guards are interfaces that let you control navigation in your Angular app. For example:
Should the user be allowed to enter this route?
Should the user leave the current route?
Should a module load at all?

This is useful for:
Authentication (allow only logged-in users)
Authorization (allow only admins)
Confirming navigation (unsaved changes)
Lazy-loading control

Angular provides these guard interfaces:
Guard Interface Purpose
CanActivate - Check if the route can be activated
CanActivateChild - Check if child routes can be activated
CanDeactivate - Check if user can leave the current route
CanLoad - Check if a lazy-loaded module can be loaded
CanMatch - Check if the route should match (Angular 15+)

What is a Route Guard?

A Route Guard is an Angular feature that controls whether a user is allowed to navigate to a route.
It acts as a checkpoint before Angular loads a component.

Types of Guards

Angular provides several built-in guards.

| Guard | Purpose |
| ------------------ | -------------------------------- |
| `CanActivate` | Allow or block access to a route |
| `CanActivateChild` | Protect child routes |
| `CanDeactivate` | Prevent leaving a page |
| `CanMatch` | Decide if a route should match |
| `Resolve` | Load data before navigation |

CanActivateChild

canActivateChild is an Angular route guard used to control access to child routes. It is useful when multiple child routes share the same authorization or authentication rule, such as protecting all admin routes with a single guard.

CanMatch

CanMatch is an Angular route guard that determines whether a route should match the current URL. It is particularly useful with lazy-loaded routes because it can prevent a route from being selected based on conditions such as user roles or permissions. Unlike canActivate, when canMatch returns false, Angular can continue looking for another route that matches the same URL.

CanMatch is a route guard that determines whether Angular should match a route at all.

canMatch decides whether a route is eligible to be matched before Angular activates or lazy-loads that route. This makes it especially useful for role-based routing and lazy-loaded features.
