Angular -Lazy Loading Modules

What is an Angular Module (NgModule)?

An Angular Module is a logical container that groups related components, directives, pipes, and services to organize an application and enable features like lazy loading and separation of concerns.

    Key Points
  • Introduced in early Angular versions
  • Uses NgModule decorator
  • Optional in Angular 15+ (standalone-first)
  • Still widely used in enterprise & legacy apps
  • Mostly used today for lazy-loaded feature modules

What is Lazy Loading?

Lazy Loading is a technique where Angular loads modules/components only when users navigate to them, reducing initial bundle size and improving application performance.

Lazy loading is a technique where Angular loads feature code only when the user navigates to a specific route, instead of loading everything at application startup.

Lazy Loading is an Angular optimization technique that loads modules or components only when they are required, reducing the initial application bundle size.

Why Lazy Loading is Used?

  • Faster initial load time 🚀
  • Smaller main bundle
  • Better performance
  • Improves user experience
  • Industry standard for large apps
  • Dashboard (eager)
  • Users (lazy)
  • Reports (lazy)
  • Admin (lazy)
  • Settings (lazy)

Example 1: Module-Based Lazy Loading

Generate Module: ng g module users --route users --module app.module
Angular automatically creates lazy loading routes.

In users-routing.module.ts

                
                    const routes: Routes = [
                        
                            path: '',
                            component: UsersComponent
                        
                    ];

In app-routing.module.ts

                
                    const routes: Routes = [
                    
                        path: 'users',
                        loadChildren: () =>
                        import('./users/users.module')
                            .then(m => m.UsersModule)
                    
                    ];
